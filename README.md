# 디스코드 기상 체크 봇

평일 아침 기상 시간을 체크하고 지각 횟수를 관리하는 디스코드 봇입니다.

## 기능

### 기상 체크
- **/기상**: 평일 오전 8시~10시 사이에 기상 체크
  - 8시~10시: 정상 처리 ✅
  - 10시 이후: 지각 처리 ⏰
  - 주말에는 작동하지 않음
  - 하루에 한 번만 체크 가능

### 자동 지각 체크 🤖
- **매일 밤 11시 59분** 자동으로 미출석자 체크
- 평일에 `/기상` 명령어를 입력하지 않으면 **자동으로 지각 처리**
- 주말에는 자동 체크 안 함
- 한 번이라도 `/기상`을 한 적 있는 모든 사용자가 대상

### 기록 확인
- **/지각확인**: 이번 달 전체 지각 현황 확인

- **/전체기록**: 최근 3개월의 지각 현황 확인 (월별로 표시)

- **/내기록**: 내 이번 달 기상 기록 상세 확인

- **/도움말**: 봇 사용법 안내

## 설치 방법

### 1. Python 설치
Python 3.8 이상이 필요합니다. [Python 공식 사이트](https://www.python.org/downloads/)에서 다운로드하세요.

### 2. 필요한 패키지 설치

터미널에서 다음 명령어를 실행하세요:

```bash
cd discord-attendance-bot
pip install -r requirements.txt
```

### 3. 디스코드 봇 만들기

1. [Discord Developer Portal](https://discord.com/developers/applications)에 접속
2. "New Application" 클릭하여 새 애플리케이션 생성
3. 좌측 메뉴에서 "Bot" 선택
4. "Add Bot" 클릭
5. "TOKEN" 아래의 "Reset Token" 클릭하여 토큰 복사 (이 토큰은 절대 공유하지 마세요!)

### 4. 봇 권한 설정 (중요!)

1. 좌측 메뉴에서 "OAuth2" > "URL Generator" 선택
2. **SCOPES**에서 다음 항목 체크:
   - ✅ `bot` (봇 기능)
   - ✅ `applications.commands` (슬래시 커맨드 - 필수!)
3. **BOT PERMISSIONS**에서 다음 권한 체크:
   - ✅ Read Messages/View Channels
   - ✅ Send Messages
   - ✅ Read Message History
4. 하단에 생성된 URL을 복사하여 접속하고 봇을 서버에 초대

**중요:** `applications.commands` 권한이 없으면 슬래시 커맨드가 나타나지 않습니다!

### 5. 봇 토큰 설정 (중요!)

**방법 1: .env 파일 사용 (권장)**

```bash
# .env.example을 .env로 복사
cp .env.example .env

# .env 파일 편집
nano .env
# 또는
code .env
```

`.env` 파일 내용:
```
DISCORD_BOT_TOKEN=여기에_복사한_토큰_붙여넣기
```

**방법 2: config.py 파일 사용**

```bash
# config_example.py를 config.py로 복사
cp config_example.py config.py

# config.py 파일 편집
nano config.py
```

`config.py` 파일 내용:
```python
DISCORD_BOT_TOKEN = '여기에_복사한_토큰_붙여넣기'
```

⚠️ **보안 주의:** `.env`와 `config.py` 파일은 절대 GitHub에 업로드하지 마세요! (`.gitignore`에 이미 설정되어 있음)

### 6. 봇 실행

터미널에서 다음 명령어를 실행하세요:

```bash
python bot.py
```

봇이 정상적으로 실행되면 "봇이 준비되었습니다!"라는 메시지가 표시됩니다.

## 슬래시 커맨드 사용법

이 봇은 **디스코드 공식 슬래시 커맨드**를 사용합니다!

### 슬래시 커맨드의 장점:
- 📝 `/` 입력 시 자동으로 명령어 목록이 나타남
- 💡 각 명령어의 설명도 함께 표시됨
- ✨ 클릭만으로 명령어 선택 가능
- 🎯 오타 방지 및 편리한 사용

### 사용 방법:
1. 디스코드 채팅창에 `/` 입력
2. 봇 명령어가 자동완성 목록에 표시됨
3. 원하는 명령어 클릭 또는 선택
4. Enter로 실행!

## 사용 예시

```
사용자: /기상
봇: ✅ 홍길동님 기상 확인되었습니다! (시간: 08:30)

사용자: /기상 (10시 30분에 입력)
봇: ⏰ 홍길동님 기상 확인되었습니다! (시간: 10:30) - 지각 처리되었습니다.

사용자: /지각확인
봇: [1월 지각 현황]
    • 홍길동님: 지각 2번
    • 김철수님: 지각 1번
    • 이영희님: 지각 0번

사용자: /전체기록
봇: [최근 3개월 지각 현황]

    [2026년 1월]
    • 홍길동님: 지각 2번
    • 이영희님: 지각 0번

    [2025년 12월]
    • 홍길동님: 지각 3번
    • 김철수님: 지각 1번

    [2025년 11월]
    • 홍길동님: 지각 1번
```

## 데이터 저장

모든 기록은 `attendance_data.json` 파일에 저장됩니다. 봇을 재시작해도 데이터가 유지됩니다.

## 주의사항

- **봇이 24시간 실행 중이어야** 명령어와 자동 체크가 작동합니다
- 하루에 한 번만 기상 체크 가능합니다
- 평일(월~금)에만 작동합니다
- 한국 시간(KST) 기준으로 동작합니다
- **자동 지각 체크**: 평일 밤 11시 59분에 `/기상` 안 한 사람은 자동으로 지각 처리
- 한 번이라도 `/기상`을 사용한 적이 있는 사람만 자동 체크 대상입니다

## 문제 해결

**슬래시 커맨드가 나타나지 않는 경우:**
1. 봇 초대 시 `applications.commands` 권한을 체크했는지 확인
2. 봇을 재시작한 후 1-2분 정도 기다리기 (디스코드 동기화 시간)
3. 디스코드 앱을 완전히 종료 후 재시작
4. 봇을 서버에서 추방 후, `applications.commands` 권한을 포함하여 다시 초대

**봇이 응답하지 않는 경우:**
1. 봇이 실행 중인지 확인
2. 봇이 해당 채널의 메시지를 읽을 권한이 있는지 확인
3. 터미널에 "슬래시 커맨드가 동기화되었습니다!" 메시지가 표시되었는지 확인

**패키지 설치 오류:**
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

**이미 봇을 초대했는데 슬래시 커맨드가 안 보이는 경우:**
- Discord Developer Portal에서 OAuth2 URL을 `applications.commands` 권한 포함하여 다시 생성
- 새 URL로 봇 재초대 (기존 봇은 자동으로 업데이트됨)
